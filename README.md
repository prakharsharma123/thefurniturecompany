# PN Modular System (Node.js + Express + EJS)

1. Install Node.js, then in this folder run: `npm install`
2. Start the site: `npm start`  (or `npm run dev` if nodemon is installed)
3. Open http://localhost:3000/home

Folders: `views/` (pages), `views/partials/` (head, header, footer, card), `views/blog/` (blog pages),
`public/` (style.css, script.js, images/). Routes are in `index.js`. Photo paths go in the IMG block in `data.js`.
